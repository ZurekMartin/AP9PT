# AP9PT

## Kinet
Mobile application for turning steps, workouts and study time into minutes spent on a virtual jellyfish

### Functionality
- Liquid Glass design
- Single Minutes Currency from Steps, Workouts and Study
- Daily Streak Bonus and Rest Days
- Study Timer with Pomodoro and Guided Breathing
- Animated Aquarium with Feeding and Mood System
- Shop with Decorations, Environments, Skins and Daily Experiences
- HealthKit Integration and Evening Reminders
- Haptics, Subtle Sounds and Demo Mode
